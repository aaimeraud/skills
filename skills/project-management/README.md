# Project management

Skills for planning work and writing it down so that any teammate can pick it up.

## Plugins

- **[linear](./linear/)**: Linear project creation. Install it once, then use its command:
  - `/linear:plan-to-project`: turns a planning discussion into a Linear project with milestones, documents and issues, in a neutral tone. A learning variant (homework style) applies when the request contains "apprentissage" or "devoir maison".
