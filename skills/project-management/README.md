# Project management

Skills for planning work and writing it down so that any teammate can pick it up.

## Plugins

- **[linear](./linear/)**: Linear project creation. Install it once, then use its command:
  - `/linear:plan-to-project`: turns a planning discussion into a Linear project with milestones, documents and issues, in a neutral tone. A learning variant (homework style) applies only when the user asks for it (for example "learning mode" or "homework").

Examples: [team project planning](../../docs/workflows/team-project-linear.md), [personal project with Linear](../../docs/workflows/personal-project-linear.md) (with the homework plugin).
