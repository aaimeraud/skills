# Education

Skills for students and self-learners: reviewing exercises, checking answers, and getting hints without being handed the solution.

## Plugins

- **[homework](./homework/)**: the homework helper. Install it once, then use its commands:
  - `/homework:setup`: one-time setup (language, subject, criteria, resources).
  - `/homework:review <exercise>`: status, score out of 5, and guiding problems.
  - `/homework:review-all`: one line per exercise.
  - `/homework:check <answer>`: is the answer right, without revealing it.
  - `/homework:hint <exercise>`: a four-step hint with documentation links.
  - `/homework:explain <topic>`: a step-by-step explanation, only when asked.
  - `/homework:resources <topic>`: free documentation for a topic.
  - `/homework:extract <file>`: converts a PDF, image or docx into markdown.
