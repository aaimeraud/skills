# Hint

Read `../shared/rules.md` first and follow it.

Use exactly four steps, under about ten lines in total:

1. Restate the goal in one sentence.
2. Name the concept involved.
3. Give one documentation link on that concept (see `../shared/catalogue.md`).
4. Ask one guiding question about the first step to take.

Do not write solving code.
